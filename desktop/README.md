# chill_hihi 桌面小寵物（macOS）

把網頁版包成一個置頂小視窗，做事時當音樂播放器和療癒小物。

## 安裝與執行

```bash
cd desktop
npm install      # 會裝 Electron，並把 three / matter-js 複製到 vendor/
npm start
```

第一次啟動：視窗在螢幕右下角，選單列會出現一個 CD 圖示（Dock 不會有圖示）。

## 兩個決定都做成選單

在選單列 CD 圖示裡切換，設定會記住：

- **版面**：完整播放器（整台 CD 播放器、遙控器、耳機、狗狗，照原本玩法放 CD）／迷你（狗狗＋小控制列，最省電）。
- **視窗樣式**：透明（預設，只有播放器浮在桌面上，透明處的點擊會穿透到後面的視窗）／圓角卡片（灰白）。狗狗預設不出現，可在選單開啟，會趴在播放器上。
- **視窗大小**：小／中／大。
- **效能**：省電／平衡／流暢；預設「使用電池時自動切到省電」。
- **暫停動畫（音樂繼續播放）**、**隱藏視窗**：畫面完全不繪製，音樂照播。鎖定螢幕時會自動暫停繪製。
- **狗狗**開關、**狗狗看著桌面上的游標**、**永遠置頂**、**接管鍵盤媒體鍵**（預設關，避免搶走其他播放器的按鍵）。

視窗左上角的 ⠿ 是拖曳握把，旁邊的 – 是隱藏視窗。

> 切換版面或視窗樣式會重新載入頁面，正在播的音樂會停止。

## 打包成 .app／.dmg（選用）

```bash
npm run dist     # 輸出在 desktop/dist/
```

沒有 Apple 開發者簽章，第一次要在 Finder 對 app 按右鍵 →「打開」。

## 運作方式

- `main.js`：本機 http 伺服器（YouTube 不能從 `file://` 播放）、透明無邊框視窗、選單列圖示。網頁來自上一層的 `index.html` 和 `models/`，改 `src/` 後要執行 `python3 tools/build.py` 再重開。
- `preload.js`：頁面與外殼之間的小橋，只有「設定是否穿透」「隱藏」「接收指令」三件事。
- 頁面端的寵物模式在 `src/16-pet/`，設定在 `src/01-core/02-pet-config.js`。

## 已知限制

- 桌面版有自己的瀏覽器儲存，和你在 Chrome／Safari 開的網頁版是分開的：在網頁版加過的播放清單、狗狗穿的衣服，要在桌面版另外設定一次。
- YouTube 影片即使看不到畫面仍會解碼，這是 IFrame API 的限制；縮小播放器只是讓它改挑低解析度，省多少由 YouTube 決定。
- 若 YouTube 在桌面版顯示「錯誤 153」之類的嵌入錯誤，代表它不接受這個來源，請回報。
