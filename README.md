# chill_hihi

灰白磨砂風的 3D CD 播放器，可以貼上 YouTube 播放清單，變成一張有封面的專輯，放進播放器依序播放。

線上版：https://balala-bubu.github.io/chill_hihi/

## 怎麼玩

1. 點左下角「＋」，貼上 YouTube 播放清單網址（`youtube.com/playlist?list=…`），按「加入」。
2. 清單會變成專輯櫃最後一格，封面是第一支影片的縮圖。
3. 點專輯，再點一下盒子打開，抓住 CD 往下拖，回到播放器畫面。
4. 點播放器掀開蓋子，把 CD 拉近播放器，放開後 CD 會跳進去、蓋子蓋上、耳機線接上，開始依清單順序播放，播完自動停止。
5. 播放器上的按鈕：▶／❚❚ 播放暫停、■ 停止（停止後再按一次會退出 CD）、－／＋ 音量。
6. 想把 CD 放回去：點播放器打開蓋子，抓住 CD 往上拉，專輯會被吸過來，放開後自動收回櫃子。
7. 點左下角「≡」可以改清單名稱、刪除清單，或按「回復預設」只留下內建的 7 張專輯。

## 限制

- 只讀公開或不公開的播放清單；私人清單和 YouTube 自動合輯（`list=` 後面是 `RD` 開頭）讀不到。
- 不能選歌，只能依清單順序播放。
- 不允許嵌入播放的影片可能會被略過。
- 必須用網址開啟（GitHub Pages 或本機伺服器），直接雙擊檔案（`file://`）YouTube 不會播放。
- 瀏覽器可能擋自動播放，第一次需要先點一下畫面。
- 加入的清單只存在自己的瀏覽器。

## 技術

單一 `index.html`，Three.js 做 3D，YouTube IFrame API 播放（讀清單的方式參考 [wvs_hitster](https://github.com/balala-bubu/wvs_hitster)，不需要 API key）。內建專輯的音樂是瀏覽器即時合成的。
