# chill_hihi

灰白磨砂風的 3D CD 播放器，可以貼上 YouTube 播放清單，變成一張有封面的專輯，放進播放器依序播放。

線上版：https://balala-bubu.github.io/chill_hihi/

## 怎麼玩

1. 滑鼠移到畫面最上方，專輯櫃會滑下來（手機點上方「專輯櫃」小標籤）；離開後自動收起。
2. 點專輯，再點一下盒子打開，抓住 CD 往下拖到播放器。
3. 點播放器掀開蓋子，把 CD 拉近播放器：艙位會浮出橘色光圈，進到可放入的範圍光圈會跳動並「喀」一聲。放開後 CD 會跳進去、砸在艙位上（衝擊波、火花、機身微微下壓），蓋子蓋上，耳機被丟進畫面、線甩動後自動插上，開始依清單順序播放。
4. 播放器按鈕：▶／❚❚ 播放暫停、■ 停止（停止後再按一次會退出 CD）、－／＋ 音量。
5. 想把 CD 放回去：打開蓋子，抓住 CD 拖到畫面最上方，專輯櫃會把它吸回去。
6. 專輯櫃最右邊、最後一張專輯的右側有顆圓形「⋯」按鈕（跟專輯同一排，隨專輯櫃出現、收起、左右捲動）：**新增**（貼 YouTube 播放清單網址）、**編輯排序**（▲▼ 調順序、點名稱改名）、**刪除**（也可回復預設）。按下去三個點會合成一個點；新增表單和編輯面板會在櫃板下方打開，點空白處或按 Esc 收起。

## 遙控器、電視、耳機

- 播放器是浮空的，旁邊的遙控器可以拖來拖去、丟出去。
- 遙控器 TV 鍵：召喚一台老電視從上面掉下來站在畫面上（播放器會往右飄讓位），播放專輯的影片，沒有影片就顯示縮圖，前面有顆粒與掃描線濾鏡；再按一次地上會開洞，電視掉進去。
- 遙控器其他鍵：震動、無重力、狗狗（原本的「重新插耳機」鍵換成狗狗；耳機插頭還是可以用手拖回插孔，放 CD 時也會自動插上）。
- **耳機浮在空中**：耳機自己的重量被抵消，用一根很軟的彈簧吊在懸浮點上，會慢慢上下漂、輕輕搖擺。拖它、丟它都行，放開後會順著丟的方向多滑一小段，然後就停在那裡繼續浮著（地板上的影子會跟著高度變淡）。
- **耳機線長度無限**：線一繃緊，靠插頭那一段就會自動放線（超過兩倍長會一分為二，畫面不跳），線永遠不會被拉斷或拉掉。拖動時線還是會甩、會碰到其他東西。
- **只有主動點按才會拔掉**：插在插孔上的插頭，**點一下**（不拖）才會彈出來；拖拉耳機、拖插頭、拉很遠都不會拔。拔掉之後把插頭拖到插孔附近放開，會自動吸回去。
- 耳機線從右耳罩下方的護線套出來，錨點和模型出線口對齊，線看起來是真的從那裡長出來。

### 耳機模型

重做過：頭帶外殼（圓角斷面，掃過弧線）加內側橘色頭墊、兩端金屬鉸鏈；耳罩是圓角方圓外殼（superellipse 車削）加外蓋板、分模線、藍色 LED 環；耳墊是橘色織紋甜甜圈，中間看得到深色喇叭網布；右耳罩下方有護線套。物理形狀沒動（耳罩方塊加頭帶弧線），只是外觀更精細。想調的地方：`makeCup`（耳罩）、`arcBand`（頭帶／頭墊）、`HOV_K`／`HOV_C`（浮空彈簧）、`NMAX`（放線的最大節數，超過後改成把最後一段越拉越長，所以還是無限）。

## 狗狗

遙控器右下角的狗狗鍵：按一下，一隻米格魯幼犬從畫面左邊跑進來；再按一下，牠跑回左邊離開。

- **平常**：站在地板上，頭一直跟著滑鼠轉，身體會慢慢轉向滑鼠；會眨眼、耳朵偶爾抖一下、尾巴輕輕搖。播放音樂時尾巴搖得更快、嘴巴微開、頭跟著拍子點。
- **拖 CD 的時候**：牠會追著 CD 跑，跑到正下方抬頭看；CD 靠近地面時會跳起來去搆。
- **有電視的時候**：電視落地後，牠跑到電視左前方坐下看電視，電視收掉就站起來走回原位。
- **跑步**：四肢交替擺動，耳朵是彈簧模擬，隨速度往後飄、隨步伐上下甩。
- **點一下狗**：牠會翻肚躺下撒嬌，滑鼠在身上移動就繼續躺著；沒人摸大約 3 秒後會慢慢起身，有小機率（約 16%）爬到一半又摔回去，再爬第二次一定成功。
- **拖 CD、關狗狗或收電視時**會打斷撒嬌，直接起身。

### 場景縱深

為了讓狗有地方跑，相機改成微微俯視（約 13 度），背景牆往後推，地板往前後拉深。電視也加了往後縮的 CRT 機尾和散熱孔，並轉一點角度，看得到機身厚度；電視下沉的洞也跟著加大。遊戲本身的 2D 物理平面不變。

### 模型與貼圖

放在 `models/`：`dog.json` + `dog.bin`（骨架、網格、蒙皮，由 FBX 轉出，約 0.9MB）和下列貼圖。載入不到時狗狗鍵不會有反應，其他功能照常。

| 檔案 | 用途 |
|---|---|
| `dog_body.png` | 身體顏色（臉、肉球、耳朵、舌頭） |
| `dog_normal.png` | 法線（原圖藍色通道是常數，已重算 Z） |
| `dog_rough.png` | 粗糙度：眼睛、鼻子、嘴巴、肉球比較光滑 |
| `dog_ao.png` | 身體的遮蔽陰影 |
| `dog_spec.png` | 高光強度（放在 alpha 通道） |
| `dog_fur.png` | 毛片顏色，**透明通道就是毛的形狀** |
| `dog_furao.png` | 毛片的毛絲細節與遮蔽 |

想調的地方：`DOG_SIT`（坐姿角度）、`DOG_LIE`（翻肚角度與下沉）、`DOG_LID`／`DOG_JAW`／`DOG_LEG`（眼皮、下巴、腿的方向與幅度）、`TILT_UP`／`TILT_DN`（相機俯視程度）。

## 質感與互動回饋

這一輪只動材質、燈光和回饋，沒有動版面、物理和操作流程。

### 質感

- **霧面機身 vs 光面按鍵**：機身是顆粒粗糙度加凹凸、柔和 clearcoat 和絲絨邊光，再疊一層正面表面層（上亮下暗、左上受光的亮邊、右下的暗邊、細顆粒），讓它像模壓件而不是一塊平灰。按鍵刻意做得更光滑，兩種材質並排，零件才有「不同東西」的感覺。
- **棚內光**：環境是上亮下暗的漸層球，加兩條邊緣光條，倒角才會有一道細亮邊。主光微暖、補光偏冷，倒角兩側有冷暖分離。
- **螢幕像 OLED**：像素格、玻璃反光、文字微微發光。
- **小細節**：艙位內凹陰影、機身四角螺絲、耳墊織紋、線材緞面反光、專輯盒與專輯櫃邊緣的亮面塑膠。
- **CD 虹彩**：反光掛在 CD 的根節點、不跟著轉盤轉，所以盤轉的時候反光不動，傾斜時才會掃過去，和真的光碟一樣。

### 互動回饋

- **同一個橘色語言**：所有回饋都用同一個強調色，而且只在「有意義的時刻」亮：按鍵、LED、引導光圈、撞擊、播放中的艙位暖光。
- **按鍵**：按下或滑過會染上暖色；播放中暫停圖示變橘。鍵面接近純白，用自發光會直接過曝，所以改成染色。
- **LED**：有光暈，調音量時被改變的那一顆會閃一下。
- **放 CD 的引導光圈**：拖近開著的艙位時浮出橘圈，進入可放入範圍（跟實際判定同一個距離）會脈動，並有「喀」聲和震動，放開就會放進去。
- **CD 砸進去**：衝擊波圈、暖色閃光、14 顆火花、艙位光脈衝、機身微微下壓、CD 微縮一下、鏡頭輕震、低頻撞擊聲加手機震動。
- **播放中**：艙位透出暖光，會跟著浮空的播放器移動。

### 設計原則

- 特效都是疊加層，不改座標、物理、轉軸，互動流程不受影響。
- 淺色底上不用加亮混合（additive），它會直接變成白色；一律用實色半透明。
- 成本很小：幾張小貼圖加一盞點光源。撞擊用的圈、閃光和火花是預先建好重複使用的，不會每次放 CD 都新建物件。
- 想調參數的地方：顆粒在 `grainTex`，機身表面層在 `face`，按鍵與 LED 與光圈在 `updateFx`，撞擊在 `impact`。

## 限制

- 只讀公開或不公開的播放清單；私人清單和 YouTube 自動合輯（`list=` 後面是 `RD` 開頭）讀不到。
- 不能選歌，只能依清單順序播放。
- 不允許嵌入播放的影片可能會被略過。
- 必須用網址開啟（GitHub Pages 或本機伺服器），直接雙擊檔案（`file://`）YouTube 不會播放。
- 瀏覽器可能擋自動播放，第一次需要先點一下畫面。
- 加入的清單只存在自己的瀏覽器。

## 技術

單一 `index.html`，Three.js 做 3D、matter-js 做 2D 物理，YouTube IFrame API 播放（讀清單的方式參考 [wvs_hitster](https://github.com/balala-bubu/wvs_hitster)，不需要 API key）。內建專輯的音樂是瀏覽器即時合成的。
