# chill_hihi 懸浮播放器（Chrome 擴充功能）

把 chill_hihi 的 3D CD 播放器浮在你瀏覽的**每個網頁右下角**：背景透明、只有播放器，按鈕照常能按，播放器以外的地方點擊會穿透到下面的網頁。

## 安裝
1. 先把這個 repo 的新版本（含 `?pet=full&ext=1` 支援）部署到 GitHub Pages，預設網址 `https://balala-bubu.github.io/chill_hihi/`；網址不同就在擴充功能圖示的彈出視窗改「播放器網址」。
2. Chrome 開 `chrome://extensions` → 開「開發人員模式」→「載入未封裝項目」→ 選這個 `extension/` 資料夾。
3. 開 chill_hihi 原網頁，「⋯」選單出現「懸浮播放器：開／關」可切換；也可以用工具列圖示的彈出視窗。

## 行為
- 懸停在播放器上會出現「⠿ 移動」「⤡」「✕」：拖曳移位置、拖曳 ⤡ 自由縮放（往左上拉變大）、✕ 關閉（重新開啟：選單或圖示）。圖示彈出視窗也有小／中／大三檔。
- 這個版本沒有專輯櫃和狗狗。選專輯：在 chill_hihi 原網頁放好 CD，再開「懸浮播放器」，它會把正在播的那張接過去。
- 關掉再重開（甚至重開瀏覽器），CD 會回到播放器裡、停在上次的位置，按播放就接著播。
- 只有**目前看著的分頁**會顯示播放器；切換或換頁後，新的播放器自動放回 CD，從同一首、同一秒接著播（換頁瞬間約有 1–2 秒空檔）。
- 開啟懸浮播放器時，原網頁自己的播放會停掉，改由懸浮播放器播放。
- 設定與播放清單存在 `chrome.storage.local`，所有網站共用。
- 耗電：沿用寵物模式的限幀（預設 30 fps，閒置 15 fps）；彈出視窗可改成省電。

## 已知限制
- 有嚴格 CSP（`frame-src`）的網站（例如部分銀行、GitHub 等）會擋掉 iframe，那些頁面不會出現播放器。
- Chrome 內建頁面（`chrome://`、網路商店）、PDF 檢視器無法注入。
- 瀏覽器的自動播放限制：換頁後第一次點擊網頁才會恢復聲音。
- 這個版本在沙盒裡用模擬的 chrome API 測過掛載、穿透點擊、拖曳、開關；真正的 YouTube 播放、換頁接續在實機還沒驗證。
